# «Живой цех» — цифровой двойник автомобильного завода

Команда «Лава» — Костанайский региональный университет имени Ахмет Байтұрсынұлы, Костанай.

**Qostanai Industry Hackathon — кейс №2: «Цифровой двойник автомобильного завода».**

## О проекте

«Живой цех» — браузерный MVP цифрового двойника производственной линии. Прототип визуализирует движение автомобилей по производственным участкам, состояние оборудования и ключевые производственные показатели, а также демонстрирует сценарий прогнозирования отказа и управленческого решения через What-if.

## Возможности MVP

- интерактивная схема производственной линии;
- движение автомобилей между участками;
- статусы оборудования: работает / предупреждение / простой;
- KPI: выпуск, выполнение плана, OEE, загрузка, простой, дефекты;
- очередь (WIP) на производственных участках;
- журнал событий и инцидентов;
- AI-панель с прогнозом риска отказа сварочного робота;
- определение узкого места;
- сценарий отказа оборудования;
- What-if-сценарии;
- расчёт потенциального экономического эффекта в тенге;
- работа полностью локально, без внешних API.

## Важно о данных

Данные в MVP являются **синтетическими демонстрационными данными** и не являются производственными данными АО «Группа компаний АЛЛЮР». Значения риска, выпуска, такта, маржи и экономического эффекта используются для демонстрации принципа работы системы.

## Запуск

Проект не требует установки зависимостей.

### Вариант 1 — открыть файл

Откройте `index.html` в браузере.

### Вариант 2 — локальный сервер

```bash
python -m http.server 8000
```

После этого откройте:

`http://localhost:8000`

## Сценарий демонстрации

1. Открыть цифровой двойник и показать состояние линии.
2. Показать движение автомобилей и KPI.
3. Перейти к AI Control Tower и показать риск отказа WR-04.
4. Запустить сценарий отказа.
5. Показать рост очереди и изменение KPI.
6. Определить узкое место.
7. Запустить What-if и сравнить варианты действий.
8. Показать потенциальный экономический эффект.

## Дальнейшее развитие

Для промышленной версии предполагается подключение реальных данных MES/ERP/1С, датчиков оборудования и исторических данных простоев; переход от синтетического симулятора к потоковой модели предприятия; расширение ML-модели прогнозирования отказов и 3D-визуализация.
